## 배경·기준

기존 웹 공지 메뉴의 준비 화면을 실제 목록·상세·작성·삭제 화면으로 연결했다. 사용자는 로컬에서 “잘 작동되는 것 같다”고 확인하고, 1번에게 협업 문서를 작성·전달하도록 요청했다. 이 수동 확인을 모든 권한·MySQL·두 PC 시험 완료로 확대하지 않는다.

코드 작업 기준은 원본 alpha `abd219bf58bf1f4ea0ee25dfe1f270f6ff31bfc2`와 보존된 기존 로컬 공지 팝업·정렬 변경이다. 게시 준비 때 확인한 최신 alpha는 `8c297a06f7ead4a1e5f14a25fb3f09a78f034224`, LOG는 `28b21d435ca1c1b46d1c6643fd94386206c4adc6`, PR 브랜치는 `9e20465fb2758d187bf0e292b4e92f30618e383b`이다. alpha 두 기준 간 서버 변경은 업무 readiness/start_dates와 해당 테스트 4파일이며 이번 공지 변경 파일과 직접 중복되지 않는다. **최신 alpha를 Desktop에 적용·결합 검증했다고 주장하지 않는다.** 실제 Desktop 폴더는 Git 저장소가 아니므로 로컬 웹 코드의 커밋·코드 PR은 아직 없다.

기존 [N4 공지 API·DDL 회신](2026-10-17_공지DB_API_DDL_협의회신.md), [공통규약 사전 협의](2026-10-19_공통규약_사전협의요청.md), [4번 C08/C09 회신](../4번/2026-10-19_C08_C09_채팅공지_협의회신.md), [2번 영역 수정 규약](../2번/2026-10-17_2번_영역수정_협업규약.md)을 기준으로 한다. 추가로 [1번 후속 문서 PR #34](https://github.com/Esp3ra/2026-Moble-2nd-Team-Project/pull/34)의 [C08/C09 기술 회신 고정본](https://github.com/jinkyu1452-cmd/Sang1/blob/1039dcda4a69c558c10b0a7e0458293105775a5c/1번/2026-10-19_C08수신_C09공지_기술검토회신.md)을 읽었다. 해당 문서는 별도 검토 중인 회신이며 원본 LOG 병합·공동 정책 확정과 구분한다. 이번 요청은 **웹 기본 공지 연결**이며 C09 팝업/확인 정책을 대신 확정하는 요청이 아니다.
