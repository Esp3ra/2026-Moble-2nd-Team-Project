MySQL은 이전 전용 QA 데이터 경로와 `127.0.0.1:13316`을 사용했습니다. 새 `remote_work_test_` DB를 만들어 검증했으며 팀 운영 DB와 원본 `.env`를 사용하지 않았습니다. HTTP 점검 서버는 `127.0.0.1:15516`에서 별도로 실행했습니다. 검증용 계정은 매 실행 무작위 비밀번호를 사용하고 결과 문서·저장소에 포함하지 않습니다.

Windows 기본 임시 경로 권한 오류는 새 작업 폴더의 `--basetemp`로 해결한 뒤 SQLite 23개가 통과했습니다. 테스트용 폴더·DB·로그·캡처·가상환경·Desktop 빌드는 커밋 대상에서 제외합니다. 공통 소스 변경은 인수인계의 WinForms 8개와 서버·실행·연결 문서·공통 점검 도구입니다. 메뉴의 결과물 표시는 기존 최신 팀 코드와 맞췄습니다.

업무 API·실제 Own/Managed 서버 조회 권한·업무 DB·상태 변경·제출·승인·파일·두 PC/웹 업무 조회는 미구현 또는 미검증입니다. 47개 조회 검증은 명시적 테스트 대역이며 실제 서버 인증·업무 DB 검증이 아닙니다. 공통 HTTP 10개는 공통 API를 대상으로 하며 업무 조회 성공을 뜻하지 않습니다. 원격 CI 결과는 별도 확인해야 합니다.

## 앞선 로컬 검증과의 구분

이전 인수인계에는 별도 MySQL 23개, C# HTTP 10개, Debug/Release와 사용자 직접 기능 확인이 기록돼 있습니다. 위 표는 최신 alpha와 병합한 뒤 이번에 다시 실행한 결과이며 이전 수치를 합산하지 않습니다. 사용자가 앞서 직접 확인한 비밀번호 변경·초기화·비활성/재활성 화면 동작을 이번에 다시 사용자 확인했다고 적지 않습니다. 이들 서버 API의 접속 폐기·권한·트랜잭션은 위 23개 서버 테스트에 포함됩니다.

공통 사용자·인증·웹과 실제 업무 조회는 구분합니다. 본인/타인 업무·관리 범위 밖 관리자·업무 없는 사용자에 대한 공유 업무 테스트 세트와 두 PC·웹 업무 검증은 후속입니다.
