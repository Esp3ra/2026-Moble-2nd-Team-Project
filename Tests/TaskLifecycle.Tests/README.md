# 2번 업무 취소·마감 연장 클라이언트 검증

```powershell
dotnet run --project Tests/TaskLifecycle.Tests/TaskLifecycle.Tests.csproj -c Release
```

명시적인 HTTP·워크플로 테스트 대역을 사용합니다. 실제 서버, 공유 DB, 실계정 검증으로 간주하지 않습니다.

- 확정된 5개 상태별 취소·신청·승인·반려·철회 입력 조건, 자기 판단 금지, 현재 배정, KST 날짜, UTF-8 사유 및 전체 JSON 32KiB 상한.
- 공통 키·결과 조회를 쓰는 정확한 API 경로·본문·최소 8개 응답 필드, 숫자/문자 ID와 별도 취소 표시.
- 응답 유실 시 본문·키 보존, 결과 확인 전 재시도 금지, `not_recorded` 뒤 동일 요청 재전송, 권한 상실 및 계정 변경.
- `write_enabled=false` 기술 연결 안내와 실행 잠금, 입력 확인/실행 분리, 세션 변경 전후 늦은 성공 차단, 읽기 전용 요청함 및 미확인 요청 복구.
- 기존 업무 조회의 취소 포함 opt-in 및 구형 서버 호환, 취소 상세의 원래 상태 유지, 새 행동 비활성, Designer 최소 크기 배치.

선택적으로 `--layout-dir <절대폴더>`를 전달하면 테스트 대역 화면의 PNG를 저장합니다. 테스트 안에서 실제 취소나 연장 요청을 실행하지 않습니다.
