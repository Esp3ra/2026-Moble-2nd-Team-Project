# 채팅 자동 수신 - 2026-10-19 PR21 갱신

실제 로그인 채팅 화면이 열려 있으면 기존 방/메시지 조회 API를1초간격으로호출한다. 새초대방과선택방의새메시지를수동재선택없이표시한다. WebSocket/SSE서버푸시가아닌주기적조회다. Designer/메모리미리보기에는자동조회를기본으로켜지않는다.

## 동작
- 화면별poll은한번에1개만진행한다. 초기조회·방선택조회·전송·생성·삭제중에는겹치지않는다.
- 방/메시지조회가모두성공하고화면/선택버전/필터/접속이그대로일때만반영한다. 방을바꾸거나전송/생성/삭제하면이미진행중인poll을취소해오래된결과가복원되지않게한다.
- 방목록과대화본문이같으면그리드/본문을다시그리지않는다. 초안·커서·필터·선택방을유지한다. 과거대화를읽고있으면스크롤과선택을유지하고맨아래에서읽을때만새본문끝을따라간다.
- 화면숨김·메뉴이동/Dispose·로그아웃/접속세대변경시조회중지/취소,재표시시자동재개. 메인화면의기존세션규약을그대로사용한다.
- 일시실패는현재대화/초안을보존하고2→4→8→10초로대기간격증가. 복구하면1초간격으로돌아간다. 실패를샘플성공으로바꾸지않는다.

## 주요 코드
- ChatControl.AutoReceive.cs: ConfigureAutoReceive/UpdateAutoReceiveState/ReceiveOnceAsync/CanApplyReceive/RenderReceivedMessages/DisposeReceiver.
- ChatControl.cs: 실제HTTP경로자동수신연결,기존수동동작의poll무효화와수명연결.
- HttpChatService.cs: IsSessionCurrent로공통CaptureSession의현재여부만노출. 새로운토큰보관/인증우회없음.

## 계약·제한
자동 조회는 기존 API를 사용한다. 1번의 2026-10-19 기술 회신으로 채팅 API·권한·UUID·개인 숨김·기본 off 규약을 수용했다. 이번 갱신에는 검토된 005 DDL과 ORM의 명시적 collation 정리도 포함한다. 운영 적용 승인은 별도다.

활성화된채팅화면마다통상초당방1회+선택방메시지1회조회하고,기존페이지조회가필요하면추가요청이있다. 현재API로전체이력을재조회하므로대규모이력/사용자수에대한부하·간격·차분cursor공개·서버push는1번/팀장과후속검토할항목이다. 채팅화면이닫힌동안의전역알림·미확인배지·WebSocket/SSE·읽음표시는이번범위가아니다.
