### R23-02 · P2 — 자식 정리 때문에 인증 만료 시 메인 종료를 취소하지 않기

위치: [ActivityPresenceForm.cs 198–203행](https://github.com/Esp3ra/2026-Moble-2nd-Team-Project/blob/dd3b3d6d8b8d59d84217190ff4367e2202d9114b/RemoteWork.WinForms/Features/Attendance/ActivityPresenceForm.cs#L198-L203). 연관 경로는 같은 head의 [MainForm.cs 134–145행](https://github.com/Esp3ra/2026-Moble-2nd-Team-Project/blob/dd3b3d6d8b8d59d84217190ff4367e2202d9114b/RemoteWork.WinForms/Shell/MainForm.cs#L134-L145)입니다.

활동 확인 창의 FormClosing은 종료 중인 경우에도 먼저 `e.Cancel = true`를 설정합니다. MainForm 인증 만료 처리는 expired=true·확인 타이머 중지 후 소유 창 Close→만료 안내→메인 Close를 한 번 실행합니다. 카메라 Stop이 끝나기 전에 안내를 닫으면 자식 종료 취소가 부모 종료까지 취소합니다. 자식은 정리 후 자기 Close만 예약하므로 메인은 그대로 남고, expired 가드와 중지된 타이머 때문에 그 경로가 다시 실행되지 않습니다.

**독립 재현:** 실제 WinForms 메시지 루프에서 일반 Form 소유자와 제품 ActivityPresenceForm을 ShowDialog로 연결했습니다. IActivityCamera.StopAsync가 TaskCompletionSource를 기다리는 대역을 주입하고 시작 버튼을 누른 뒤 아래 순서로 실행했습니다. Pi/카메라/서버·실제 인증 요청은 사용하지 않았습니다.

```csharp
child.Close();
host.Close(); // 인증 만료 안내를 정리 완료 전에 닫은 뒤의 부모 Close 순서
camera.Completion.TrySetResult();
await Task.Delay(250);
// 기대: 자식 정리가 끝나면 부모도 종료되어야 함
```

실제 결과: `host disposed immediately=False; child disposed after cleanup=True; host disposed after cleanup=False; host visible=True; stop calls=1`. 부모·자식 종료 동작은 실행 재현했고, 인증 만료 진입 순서는 MainForm 코드와 대조했습니다. 이 결과를 서버 권한 검사 우회나 실제 만료 API 통합 시험으로 확대하지 않습니다.

**수정 방향:** 소유자 종료가 한 번 취소됐다면 자식 정리 완료 후 소유자 종료를 확실히 이어가거나, 소유자 종료 경로에서 자식 정리가 부모 종료를 취소하지 않도록 수명을 조정해주세요. 소유한 프로세스만 정리하는 기존 기준과 일반 사용자의 모달 닫기 동작을 유지해야 합니다. 공통 MainForm/인증 변경이 필요하면1번에게 영향·수정 범위를 먼저 공유해야 하며, 이번 요청이 공통 코드 수정 승인 자체는 아닙니다.

**재검토 조건:** Stop이 즉시 끝나는 경우와 지연/강제 종료되는 경우 모두에서 일반 닫기·부모 닫기·인증 만료 후 안내 즉시/늦게 닫기를 검사해주세요. 카메라/조도/자식 프로세스가 해제되어야 합니다. 일반 모달 닫기에서는 메인을 유지하고, 부모 닫기·인증 만료에서는 메인 종료와 로그인 화면 복귀가 한 번 완료되어야 합니다. 기존156검증/30개·R23-01·Release 회귀도 유지하고, 테스트 대역과 실제 인증/장비 검증을 구분해주세요.
