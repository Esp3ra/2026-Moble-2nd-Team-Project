## 유지하는 경계·영향

- 카메라 장치는 사용자가 시작 버튼을 누른 후에만 연다. 다른 번호 카메라를 자동 탐색하지 않는다. 프로그램 시작만으로 영상/마이크를 수집하지 않는다.
- 물리적인 촬영 범위는 웹캠 각도로 맞춘다. 원본은 PC 메모리에 들어온 뒤 자르며 **crop은 얼굴/배경 자동 제거가 아니다**. 선택 영역 안에 들어오면 보일 수 있음을 화면과 안내에 명시.
- 원본 프레임은 모델/UI로 보내지 않고 잘린 영역만 처리. 영상·사진·특징점·판정 이력을 파일 또는 서버에 저장/전송하지 않음. 실행 코드에 네트워크 API 없음. 설치 때만 패키지와 공식 모델 다운로드.
- 손 감지/손 미검출·확인 필요/카메라 오류/지연을 구분. 미검출을 자동 이석·퇴근·결근으로 바꾸지 않음. 손이 검출돼도 신원·실제 근무·대리 여부가 증명되지 않음.
- 지문·조도·OLED·라파 서비스, 공통 서버·인증·회원·DB·근태·WinForms·다른 담당 업무 코드는 변경하지 않음. 새 공통 API/DTO/DB 변경 없음.
- 촬영 위치와 사용 목적의 사용자 확인만 반영했다. 감시 주기·판정 지속시간·자동 근태·원격 영상 전송·보관 정책을 승인받았다고 취급하지 않음.
