## 배경과 실제 변경

기존 라파에서 지문 센서와 OLED는 수동 Python 프로그램으로 동작했다. Mega가 조도값을 USB로 송신하고 라파의 지문 API와 조도 읽기가 같은 OLED/장치를 중복 제어하지 않도록 한 프로세스로 묶었다. Windows에서 curl 외에 상태를 계속 볼 수 있는 독립 점검 화면을 준비했다. 현재 사용자 장치에서는 systemd 서비스와 재부팅 자동 실행도 확인했다.

## 장치 시연 계약과 영향

| 항목 | 실제 동작 / 제한 |
|---|---|
| 지문 | 기존 `POST /scan`, 8080 유지. 한 요청만 실행, 손가락 떼기/올리기 각각 최대15초. 성공200, 미등록200+`success=false`, 사용 중409, 초과408, 오류500 |
| 식별 결과 | 센서 슬롯·표시 이름·센서 점수. 회원 ID/신원 증명/로그인 세션이 아님. 센서 점수는 확률이 아님 |
| 조도 | 190 이상 COVERED,186 이하 CLEAR,187~189 이전 상태. 첫 값·재연결은 기준 설정으로 취급 |
| 최근 변화 | 상태 변화 후10초 이내 recent_motion. 가림 해제와 별개. 3초 유효 데이터 끊김 또는 USB 오류는 확인 불가로 표시하며 이석으로 판정하지 않음 |
| API/시각 | health와 /motion 응답은 독립 시연용. 기록 시각 KST. 기존 공통 Bearer·UTC·회원/업무 응답 계약은 변경하거나 승인받은 것이 아님 |
| OLED·동시성 | 지문 안내 우선, 결과3초 유지. USB 수신과 조도 조회는 계속. 한 프로그램만 하드웨어를 소유 |
| DB·공통 영향 | 공통 DB·schema version·마이그레이션·로그인·업무 상태·출퇴근·연차·WinForms 변경 없음 |

조도는 SZH-SSBH-011과 고정 광원 아래 손가락 그림자로 다리 움직임을 모의실험한 것이다. 실제 재석 정확도 또는 실제 다리 움직임 검증을 수행했다고 기록하지 않는다.

## 실제 검증 근거

### 게시본에서 작성자가 실행한 자동 검증

환경: Windows Python3.14.7, Tk9.0. Pi 하드웨어 대역 테스트 환경 Flask3.1.3/tzdata2026.5. 하드웨어 드라이버는 main에서만 초기화하므로 Pi 없이 실행 가능.

```powershell
# Devices/RaspberryPi 폴더, requirements-test.txt 환경
python -m unittest -v test_motion_tracker test_pi_api test_local_names
# Tools/DeviceCheck 폴더, 표준 라이브러리
python -m unittest -v test_device_check
```

- 첫 묶음23개 통과: 조도 기준/히스테리시스·최근 변화·수신 끊김/재연결, Flask 응답·센서 잠금·OLED 우선순위·단일 USB/CSV 대역, 이름표 로더.
- 두 번째 묶음14개 통과: 응답 검증·HTTP 오류/JSON, 임시 HTTP 서버 통신, 실제 Tk 위젯 상태/작업 스레드 경로, 늦은 응답·연결 끊김·지문 중 조도 갱신.
- Python 문법 검사, 변경 diff/개인값·생성 파일 제외, 로컬 이름표/CSV/서비스 설정의 Git 제외 확인.
- 기존 배포본의 health/motion GET은 작성자 PC에서도200 응답을 확인했다. 지문 요청은 작성자가 원격으로 대신 보내지 않았다.

### 사용자가 직접 수행해 대화로 확인한 기존 배포본의 장치 검증

1. 센서 실인식의 `success=true` 응답 확인. 실명·생체 관련 상세 응답은 이 문서에 옮기지 않음.
2. 조도 가림/해제 및 최근 변화 응답, Pi 내부와 Windows PC의 health/motion/scan 확인.
3. Windows 장치 점검 화면 동작 정상이라고 사용자 확인.
4. `systemctl enable --now attendance-device.service`: enabled/active와 health success/motion_available 확인.
5. 사용자 재부팅 후 새 서비스 실행 상태와 health success/motion_available, PC 조회 지속을 확인.

기존 Pi 배포본의 전체 파일 해시·설치 패키지 버전은 수집하지 않았다. 이번 게시 때 실명 제거/로컬 JSON 로더와 Windows 기본 주소 일반화를 추가했으므로 이 커밋 전체를 Pi에 재배포해 실검증했다고 표시하지 않는다. 기존 실행본·이름표·서비스는 게시 과정에서 바꾸지 않았다.

### 미실행·미구현

- 게시본 전체의 실제 Pi 재배포와 새 로컬 이름표 파일 적용.
- Arduino IDE/CLI 새 빌드, 하드웨어 분리/재연결 전체 시나리오, 장시간/강제 전원 장애·망 분리 시험.
- 운영용 장치 인증/암호화·결과 신선도/위변조·계정 일치·세션/DB 저장·실제 WinForms 연결.
- 실제 재석·이석 정확도, 출퇴근/업무 수락·제출과 자동 연계.
- 공통 서버·DB 및 C# 회귀는 해당 코드를 바꾸지 않아 이번 작업에서 재실행하지 않음. 과거 다른 담당 수치를 이번 결과에 합산하지 않음.
