## [P2] 작성 가능한 디자인팀 공지를 목록에서 필터링할 수 없음

공지 작성 화면의 대상은 전 직원·기획팀·개발팀·디자인팀입니다. 그러나 목록 대상 필터에는 전체·전 직원·기획팀·개발팀만 있고, 선택값을 실제 조회 조건으로 바꾸는 코드에도 디자인팀이 없습니다.

재현 순서:

1. 관리자 화면에서 공지 작성 창을 엽니다.
2. 대상을 디자인팀으로 선택해 공지를 등록합니다.
3. 전체 목록에 등록한 공지가 나타나는 것을 확인합니다.
4. 목록에서 디자인팀만 선택하려 하면 해당 선택지가 없어 필터링할 수 없습니다.

## 수정 요청

- 작성 대상과 목록 필터의 대상 집합을 일치시켜 주세요. 목록의 `전체`는 필터 해제 항목으로 유지합니다.
- 콤보박스 표시값과 조회 조건 매핑을 함께 수정하고, 가능하면 같은 대상 정의를 사용해 재누락을 막아 주세요.
- 기존 로컬 메모리 저장·화면 전환 범위에서 수정합니다. 이 요청을 위해 서버·DB·공통 인증이나 다른 담당 기능을 추가할 필요는 없습니다.

## 수정 후 확인할 항목

- 디자인팀 공지 등록 → 목록 새로고침 → 디자인팀 필터에서 해당 공지 조회.
- 전체·전 직원·기획팀·개발팀 필터의 기존 동작 유지와 다른 팀 공지 혼입 여부.
- 일치하는 공지가 없을 때 빈 목록 표시와 상세 선택 해제.
- 대상 필터 변경·정렬 후에도 상단 고정 공지의 우선 표시와 선택한 공지의 상세 조회 유지.
- 현재 필터와 다른 대상으로 등록한 경우를 포함한 등록 후 새로고침 동작.
- 기존 관리자 삭제·직원 삭제 거부와 로컬 채팅 동작에 영향이 없는지 확인.
