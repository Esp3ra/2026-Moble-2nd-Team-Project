# 로그인·공통 레이아웃·메뉴 정리

- 기록일: 2026-10-16
- 기록 범위: 도구상자에서 수정할 수 있는 표준 WinForms 폼으로 전환한 이후의 화면 정리
- 반영 상태: 로그인·공통 배치·메뉴 순서·안내 문구 정리는 `alpha`와 `0.0.2V`까지 기게시된 내용
- 추가 상태: 직원·관리자 메뉴 이름을 모두 `결과물`로 맞춘 부분은 현재 로컬 수정본

## 변경 전과 후

| 항목 | 변경 전 | 변경 후 |
|---|---|---|
| 로그인 배치 | 왼쪽 남색 소개 박스와 로그인 영역으로 분리 | 소개 박스를 제거하고 로그인 입력 영역 중심으로 단순화 |
| 회사명 | 회사명 표시 영역이 없음 | 상단에 회사명 영역 추가, 확정 전 문구는 `회사명` |
| 지문 로그인 | 지문 로그인 진입 버튼이 없음 | `지문으로 로그인` 버튼의 외형과 준비 중 안내 추가 |
| 사원 정보 | 상단 정보와 왼쪽 아래 초안 안내 영역으로 나뉨 | 왼쪽 아래에 이름·역할·부서·사번 표시 |
| 초안 문구 | 화면 기본 틀·샘플 데이터 등 반복 안내 노출 | 반복 안내와 예시 문구 제거 |
| 제목 아래 안내 | 확인·입력·작성 방법을 설명하는 일반 문장 표시 | 해당 Label과 빈 행을 제거하고 제목 영역 축소 |
| 업무 이력 | 직원 메뉴에서도 노출 | 관리자 메뉴에만 노출 |
| 결과물 메뉴 이름 | 역할에 따라 문구가 달랐음 | 직원·관리자 모두 `결과물`로 통일한 로컬 수정본 |

## 현재 메뉴 구성

- 직원: 공지 → 업무 → 채팅 → 결과물 → 출퇴근·연차
- 관리자: 공지 → 업무 → 채팅 → 결과물 → 업무 이력 → 출퇴근·연차
- 공지를 첫 화면으로 표시하며 가운데 영역에서 기능별 UserControl을 전환합니다.
- 사원 정보는 선택한 화면 검토용 역할에 따른 고정 정보입니다.

## 현재 UI 작동 범위

- `직원 화면`·`관리자 화면` 버튼으로 각 화면을 열 수 있습니다.
- 메뉴 이동과 창 열기·닫기, 입력 항목 편집과 스크롤은 동작합니다.
- `시작 화면` 버튼이나 메인 창 닫기로 로그인 화면에 돌아옵니다.
- 아이디·비밀번호 로그인과 지문 로그인은 기능 준비 중 안내만 표시합니다.
- 역할별 메뉴 표시는 실제 인증·서버 권한 검사를 대신하지 않습니다.

## 향후 연결·합의 필요

- 회사의 실제 명칭을 확정하고 표시 문구를 교체해야 합니다.
- 실제 로그인 구현 시 인증된 사용자 역할에 따라 화면으로 자동 진입하도록 할 계획입니다.
- 현재 화면 검토용 역할 선택 버튼은 그 단계에서 대체할 예정입니다.
- 로그인 인증·만료·로그아웃과 지문 장치 연결 방식은 공통 인증 담당과 연결 규격 합의가 필요합니다.
- 이 기록은 화면 변경 이력이며 기능 배포나 태그 갱신을 수행했다는 뜻이 아닙니다.
