- 기록일: 2026-10-16
- 기록 범위: 도구상자 폼 전환 이후 공지 목록·작성·상단 고정 공지 화면의 수정
- 반영 상태: 아래 화면 수정은 `alpha`와 `0.0.2V`까지 기게시된 부분

## 변경 전과 후

| 항목 | 변경 전 | 변경 후 |
|---|---|---|
| 중요도 구분 | 중요·일반 구분과 구분 선택 항목 표시 | 중요·일반 구분과 선택 항목 제거 |
| 공지 목록 열 | 구분·제목·대상·등록일 | 대상·제목·작성자·등록일 |
| 공지 대상 | 목록 뒤쪽에 대상 표시 | 첫 번째 열에 대상 표시 |
| 작성자 | 목록에서 작성자를 확인하기 어려움 | 작성자 열 추가 |
| 확인 버튼 | 공지 확인 버튼과 팝업 미리보기 버튼 배치 | 두 버튼을 공지 목록·상세 화면에서 제거 |
| 작성 양식 | 제목·대상·중요도·본문 중심 | 중요도 선택을 제거하고 상단 고정 체크박스 배치 |
| 본문 공간 | 여러 입력 항목과 공간을 나눠 사용 | 본문 입력 행이 남은 높이를 사용하도록 확대 |
| 공통 문구 | 제목 아래 일반 안내와 초안 문구 표시 | 안내 Label과 해당 행 제거 |

## 현재 화면 구성

- 직원과 관리자는 공지 목록 및 고정된 공지 상세를 확인합니다.
- 공지 작성 버튼은 관리자 화면에만 표시하며 작성 Form을 엽니다.
- 작성 Form에 공지 제목·대상·상단 고정·본문과 첨부파일 선택 버튼을 배치했습니다.
- `ImportantNoticeForm`은 `상단 고정 공지` 제목과 본문, 닫기 버튼으로 정리했습니다.
- 목록의 팝업 미리보기 진입 버튼을 삭제했으므로 공지 화면에서 해당 팝업을 직접 열지 않습니다.
- 마감 알림 영역은 고정된 업무명·마감일·상태를 표시하는 화면 요소입니다.

## 현재 UI 작동 범위

- 관리자 공지 작성 창 열기·닫기와 입력·선택·상단 고정 체크는 가능합니다.
- 조회·첨부파일 선택·공지 등록은 기능 준비 중 안내만 표시합니다.
- 목록 행을 선택해도 상세 데이터가 바뀌지 않으며 실제 조회·필터링은 연결하지 않았습니다.
- 공지 등록·저장·발송·읽음 기록과 전 직원 팝업 전달은 구현하지 않았습니다.
- 상단 고정을 체크하는 것만으로 공지를 정렬하거나 다른 프로그램에 팝업을 보내지 않습니다.

## 향후 연결·합의 필요

- 관리자만 공지를 작성·발행할 수 있도록 서버 권한 검사를 연결해야 합니다.
- 상단 고정 공지 등록 후 전 직원 프로그램에 강조 팝업을 전달하는 요구사항은 기능 구현 단계에 연결합니다.
- 대상 범위, 전달 시점, 재접속 시 표시 여부와 반복 팝업 방지 조건은 관련 담당과 합의가 필요합니다.
- 마감 알림의 시간 감지와 변경 반영도 현재 정적 표시와 구분하여 구현해야 합니다.
