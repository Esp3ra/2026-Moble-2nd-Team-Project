# alpha와 기존 0.0.2V 동기화

정리일: 2026-10-16

[변경 기록 목록으로](../../README.md) · [18. 합의 문서·Word 정리](18_합의문서_최신화와_Word_정리.md) · [19. 업무 조회 연결 준비](19_업무목록_상세_조회연결_준비.md)

사용자가 기존 `0.0.2V`를 최신 alpha와 맞추도록 요청한 내용을 반영했다.
이번에는 alpha·0.0.2V·DOCX의 원격 참조 3개를 함께 갱신했다.
기존 태그 객체를 정확히 지정한 lease와 atomic 게시를 사용했고, 게시 후 원격 참조를 재확인했다.

## 동기화한 범위

- alpha에 먼저 반영했던 `/DOCX/` 제외 규칙과 코드·문서 게시 정책을 0.0.2V에도 포함했다.
- README의 버전·실제 구현 범위·파일 위치·검증 결과를 이번 게시본에 맞췄다.
- 업무 목록·상세의 읽기 조회 인터페이스와 화면 연결 준비를 같은 코드 커밋으로 게시했다.
- 조회 경계와 테스트 대역의 구체적인 기능·한계는 후속 기록 19에서 다룬다.
- 별도 요청에 따른 DOCX 브랜치 갱신과 Word 정리는 후속 기록 18에서 다룬다.

코드 게시 변경 파일은 16개이며, 원격 alpha와 0.0.2V의 파일 수는 각각 85개다.
DOCX 브랜치는 별도 문서 트리이며, 코드 브랜치의 로컬 DOCX 자동 제외 정책은 유지한다.
이번 게시가 실제 HTTP·인증·서버 권한 검사·DB 연동 완료를 의미하지 않는다.

## 게시 확인 결과

근거는 `before-refs.txt`, `prepared-publication.json`, `published-verification.json`이다.
원격 alpha와 태그 대상 커밋이 동일하고, 원격 파일 blob 트리가 준비한 로컬 게시본과 일치함을 확인했다.
DOCX를 포함한 원격 참조 3개가 준비한 값과 일치함을 확인했다.
코드·문서 동시 게시 당시 `main`, `LOG`, `0.0.1V`의 원격 참조는 변경하지 않았다.
원본 작업 폴더의 코드 파일 85개도 Git 줄바꿈 정규화 규칙을 적용한 blob이 게시본과 모두 같음을 확인했다. 근거는 `local-code-tree-verification.json`이다.
기존 기록은 당시 이력으로 보존하며, 이 LOG 문서의 후속 게시와 코드·문서 동시 게시 시점을 구분한다.
