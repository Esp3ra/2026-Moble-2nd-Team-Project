# 2번 담당 구현 기록

## 현재 구현 범위

현재 alpha 기준은 [3b09480](https://github.com/Esp3ra/2026-Moble-2nd-Team-Project/commit/3b0948025c440b9d3a36da82f464b0bc08557493)이며 0.0.2V는 이전 8f09183으로 보존합니다. 공통 기반을 재사용한 목록·상세 GET·실제 HTTP·격리 DB·기존 WinForms 읽기 연결을 구현했고, 1번이 현재 조회 API·DTO·권한·오류·상태/날짜 표현·공통 FK 기준을 수용했습니다. 관리 범위는 업무별 지정 관리자만입니다. 예약002의 DDL·검증/복구안은 검토 초안이며 버전1·기본 off를 유지합니다. 3번의 쓰기/제출/마감 의미와 정식 DDL·공유 DB·두 PC는 별도 합의/검증이 필요합니다.

## 추가 확정 지문센서 용도

[원격 근무 본인 인증으로 변경한 기록](2026-10-17_지문센서_원격근무_본인인증_용도변경.md)에 따라 로그인의 지문 버튼을 제거하고 기준 문서를 반영했습니다. 장치 인증은 5번 담당 범위이며 2번의 업무 조회·상태·마감 API에 인증 조건을 추가하지 않았습니다. 인증 요청 시점·주기·응답 시간·미응답/실패 처리·출퇴근 연계·장치/사용자 연결은 1·5번 등과 합의 필요입니다. 실제 LoginForm 기본/최소 크기2개·Release 경고0/오류0을 확인했습니다. 센서와 실제 계정 로그인은 이번에 검증하지 않았으며 이전 조회/DDL 회귀 수치는 아래 당시 기록에 보존합니다.

## 이전 1번 회신 반영과 다음 구현 경계

[수신 확인·M1-01~10 추적표](2026-10-17_1번회신_수신확인_및_조회규약반영.md)에 1번 수용 범위와 3번 공동 확인 항목을 나눴습니다. 기존 읽기 동작은 유지하며 README·계약·공통 연결 안내·설명 주석을 갱신했습니다. [예약002 DDL 검증](2026-10-17_002업무DDL_초안_검증.md)은 현재 모델과 일치하는 SQL, 기존 공통 행 보존, raw DDL 위의 Flask test client 권한 검사와 실제 fixture dump/restore를 기록합니다.

전용 DDL23통과(전체 MySQL61개에 포함), 전체 서버 SQLite47통과/14생략·MySQL61통과를 확인했습니다. 마지막 가드 오류 출력 보호 후 오프라인11통과/12생략과 잘못된 설정1건의 연결 전 거절·비밀값 출력 제외도 별도 확인했습니다. 개발/로컬 Release는 경고0·오류0, 로컬 변경10개·추적 소스155개 일치·DOCX7개 해시 보존입니다. 공유 DB·새 DDL의 TCP/C#/화면·두 PC 통합은 이번에 실행하지 않았습니다. 중복 테스트 수치를 합산하지 않습니다.

3번 회신으로 전환 책임·제출/판단 트랜잭션·상위 검토자·반려/마감 의미·배정 차수/제출 FK를 맞춘 뒤 1번 DDL/버전 지원 검토와 2번의 저장 구현으로 이어갑니다. 자동 결과 제출은 제외하며 자동 검토 요청은 합의 필요입니다. 공유 적용은 공식 환경·백업/복구·팀장 일정 확인 후 진행합니다.

## 이전: 합의 전 독립 개선

[진행 가능 범위](2026-10-17_합의전_진행가능범위_점검.md)를 점검하고 [선택 유지·상세 재시도·취소](2026-10-17_조회_선택유지_상세재시도_취소처리.md), [상태 필터 응답 검증](2026-10-17_조회_상태필터_응답검증_보강.md)을 진행했습니다. API/DB·권한·5개 상태·3번 기능의 합의는 변경하지 않았습니다.

이번 검증은 실제 WinForms+조회 대역9시나리오/82검증, 공통 ApiClient+HTTP 대역+화면6/103, 기존 공통HTTP18/88과 개발/로컬 Release 경고0·오류0입니다. 기존 소스에서 새 회귀가 실패하는 것도 확인했습니다. 실제 서버/MySQL·공유 DB·두 PC·웹은 이번 회차에서 재실행하지 않았습니다.

## 이전 실제 조회 개발 검증과 합의

[구현 기록](2026-10-17_업무목록_상세_실제조회_개발초안.md)에 18개 파일·테스트·미실행 범위를, [API·DB 합의 정리](2026-10-17_업무조회_API_DB_합의초안.md)에 사용자 확정/개발 코드/관련 담당 합의를 구분했습니다. Release0경고/0오류, HTTP대역4/77·기존UI6/47·공통HTTP18/88·공지채팅5/85, 서버SQLite35통과2생략·MySQL37통과·추가가드1통과, 실제HTTP+MySQL+화면은 직원19/관리자21검증 통과입니다. 테스트 fixture를 운영 업무로 표시하지 않습니다.

로컬 작업 폴더 최신 반영: 이번 코드4개·문서2개 반영, 추적 소스155개 일치·DOCX 나머지5개 해시 보존·Word 정본1개·Release 경고0/오류0입니다. 직전 회신/DDL 작업의 변경10개·DOCX7개 보존은 당시 기록으로 구분합니다. 이전 조회 개선11개/소스152개 및 개발 회차18개 반영 수치는 해당 당시 기록에 보존합니다.
