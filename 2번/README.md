## 이어서 구현할 순서

1. 3번과 초기 저장·수락·단일 상태·제출 트랜잭션·배정 차수/버전·상태별 수정 조건을 맞춥니다. 1번과 쓰기 권한 재검사·오류·사용자 식별·FK/동시성 지원을 대조합니다.
2. 2번의 **등록/배정 → 본인 수락 → 마감 신청/처리**를 합의된 행동별 API·DB로 나눠 연결합니다. 마감 시간대/당일 종료·연장·기한 후 직접 제출 조건은 확정 후 적용합니다.
3. 3번이 제공한 제출/검토 계약과 연결하고 격리 환경에서 권한·중복·경합·rollback을 검증합니다. 정식 DDL/버전·공식 환경 준비 후 공유 적용/두 PC 검증을 진행합니다.

모든 정식 제출·재제출은 승인 또는 반려를 거치며 승인완료만 최종 완료입니다. 관리자 본인 업무도 수락·제출하고 상위 검토자가 판단합니다. 자기 판단은 금지합니다. **자동 결과 제출은 제외**, 자동 검토 요청·반려 후 복귀는 합의 필요입니다. 지문센서는 원격 근무 중 본인 인증/인증 시점 재석 확인 용도이며 2번 업무 처리 조건으로 추가하지 않습니다.
