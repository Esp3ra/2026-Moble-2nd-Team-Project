## 현재 구현 범위

현재 소스 기준은 alpha·0.0.2V의 [8f09183](https://github.com/Esp3ra/2026-Moble-2nd-Team-Project/commit/8f09183ef992606ec4c2b7e3da79ef07983ba019)입니다. 현재 코드의 완료 범위는 **읽기 인터페이스와 명시적 테스트 대역을 통한 화면 연결 준비**입니다. 1번 공통 소스를 PR #2에서 확보해 별도 테스트 환경으로 검토했습니다. 공통 인증·HTTP에서 수정 요청 3건을 재현했습니다. 현재 PR #3 문서는 LOG에 병합됐고 PR #1·#2 코드는 수정 후 재검토합니다. 수정 요청 정본은 PR 브랜치의 담당별 폴더이며 병합 이력은 아래 기록에 남깁니다. 업무 조회 API 규약과 실제 HTTP 연결·서버 권한 검증은 남아 있으므로 실제 업무 데이터 연동 완료로 표시하지 않습니다.

## 담당 경계와 합의

- 1번의 인증 사용자·공통 HTTP·오류·DB 연결 규약은 2번이 대신 구현하지 않습니다. 실제 서버는 본인 배정·허용된 관리 범위와 상세 직접 접근 권한을 검사해야 합니다.
- 3번의 제출·재제출·제출 차수 표시·파일·승인·반려·이력과 4·5번의 기능은 해당 담당과 분리합니다. 화면 뼈대가 있다는 이유로 연결 완료로 기록하지 않습니다.
- 5개 업무 상태와 모든 정식 제출의 필수 검토는 확정 기준입니다. 상태 저장 코드·상위 검토자 매핑·반려 후 복귀 시점·마감 세부 조건은 합의 필요입니다.
- 자동 결과 제출은 제외합니다. 자동 검토 요청의 도입 여부·조건은 합의 질문으로 유지합니다.
