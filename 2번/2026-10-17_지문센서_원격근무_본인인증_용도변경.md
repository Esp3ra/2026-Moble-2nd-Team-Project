# 지문센서 용도를 원격 근무 본인 인증으로 변경

현재 기준은 [공통규약](공통규약.md), 구현·게시와 실행/미실행은 [업무 구현·검증](업무_구현검증.md), PR 상태는 [통합 검토 기록](PR_검토기록.md)을 먼저 확인합니다. 아래 본문은 기존 전달 경로를 유지하는 작성 당시 기록입니다. 신규 관리자 준비 UI·별도 개발 등록 API의 후속 게시 상태가 당시의 미게시 표현보다 우선합니다.

작성일: 2026-10-17 · 사용자 추가 확정 사항

## 확정된 기준

지문센서는 **로그인 이후 원격 근무 중 본인 인증 수단**으로 사용한다. 계정 로그인은 아이디·비밀번호와 기존 1번 서버 인증을 유지한다. ‘지문으로 로그인’이라는 과거 폼 요청과 로그인 연결 대기 안내는 이 결정으로 대체한다. 사용자는 본인이 근무 자리에 있는지 확인하는 용도로 설명했다. 기획 목적은 **지문 인증 시점의 본인 재석 확인**으로 정리하며 구체적인 요청 방식은 합의 필요다.

이 결정만으로 근무 시작/수동/주기적/무작위 인증 중 하나를 확정하지 않는다. 인증 성공을 출근·퇴근·업무 수락·제출·승인으로 자동 연결하지 않는다. 기존 얼굴 인식·출퇴근·연차 기능 자체를 삭제하거나 용도를 임의 확장하지 않는다.
